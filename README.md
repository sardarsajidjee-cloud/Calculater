# Smart Calc with History 🔢💾

A sleek and efficient calculator application that goes beyond simple arithmetic by keeping track of your calculation history. No more forgetting your previous results!

## 🌟 Key Features
* **Standard Arithmetic:** Seamlessly perform Addition, Subtraction, Multiplication, and Division.
* **Persistent History:** Automatically saves your calculation logs (e.g., `5 + 10 = 15`) so you can refer back to them.
* **One-Tap Clear:** Options to clear current input or wipe the entire history.
* **Responsive Design:** Works perfectly across different screen sizes.
